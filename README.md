## 🔬 Research & Neuro-AI Focus

### 🧠 Neural Signature Analysis for Cognitive States (Current Project)
Developing a Neuro-AI framework to decode cognitive processes—specifically memory retrieval and risk-related decision-making—using neuroimaging data. 
* **Pipeline:** `fMRI` → `Preprocessing` → `Representation Learning` → `Cognitive State Modeling` → `Symbolic Reasoning`
* **Technologies:** Python, PyTorch, fMRIPrep, Nilearn, BiGRU, PyReason.
* **Goal:** Integrating deep learning with structured symbolic reasoning to achieve highly interpretable representations of cognitive processes.
